# KFC Advertising Website

Многостраничный учебный рекламный сайт в стиле KFC.

## Файлы

- index.html — главная
- menu.html — меню с фильтрами
- promotions.html — акции
- about.html — о бренде
- contacts.html — контакты и форма
- style.css — общий дизайн
- script.js — интерактив

## Запуск

Открой `index.html` в браузере.

Проект не использует backend. Форма контактов работает как демонстрация и не отправляет данные на сервер.

Примечание: проект является учебной концепцией. Для коммерческого использования нужно соблюдать права на товарные знаки, фирменные материалы и фотографии KFC.
