# KFC Advertising Project v3

Многостраничный учебный рекламный сайт.

Главная: новый красный KFC-style hero-блок, крупная condensed-типографика, логотип, интерактив и адаптив.

Файлы:
index.html
menu.html
promotions.html
about.html
contacts.html
style.css
script.js
server.py
kfc-logo.svg

Запуск:
python server.py

Примечание: это учебная концепция. Для коммерческого использования официальных товарных знаков, фотографий и бренд-материалов необходимо иметь соответствующие права.
